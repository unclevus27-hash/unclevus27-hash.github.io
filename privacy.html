YT Radar – Privacy Policy

Last updated: November 26, 2026

What the app does

YT Radar is a personal desktop application used only by its owner to read analytics of YouTube channels that the owner manages.

Data accessed

With the user's consent through Google OAuth, the app requests read-only access to:

  • YouTube channel and video information (YouTube Data API)
  • YouTube Analytics and Reporting data for the authorized channel (views, watch time, impressions, click-through rate, traffic sources, audience retention, audience demographics in aggregate)

The app does not request permission to upload, edit, delete or publish any content.

How data is used and stored

  • Data is used only to display reports to the channel owner.
  • Data and access tokens are stored only on the owner's own computer. There is no server and no database operated by the app.
  • Data is not sold, shared, or transferred to any third party, and is not used for advertising.

Google API Services User Data Policy

YT Radar's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at https://myaccount.google.com/permissions. Deleting the app's local data folder removes all stored data.
